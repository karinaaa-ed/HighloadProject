# Инициализация базы данных

Эта папка содержит файлы для инициализации PostgreSQL при первом запуске контейнера.

## Файлы
- `init.sql` — пример SQL-скрипта, который создаёт расширения (можно дополнять по необходимости).
- `README.md` — описание назначения каталога.

## Как работает
PostgreSQL автоматически выполняет все `.sql` и `.sh` файлы из каталога
`/docker-entrypoint-initdb.d` при создании нового тома с данными.
В docker-compose этот каталог примонтирован из `docker/db/init`.
